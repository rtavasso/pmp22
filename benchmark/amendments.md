# Protocol amendments

## 2026-09-10 — supplemental checks after the version 1 test run

The chromosome split, labels, original feature sets, regularization grid and
reported version 1 results remain frozen. After observing those results, add
the conservation comparator required by the original research contract, using
UCSC phastCons100way mean and covered fraction on the exact same windows.
Fit and select its regularization on the original train/validation sets only.
This is an explicitly supplemental, post-test comparator, not a new primary
model selection exercise. Conservation uses a multispecies alignment, so its
information differs from the single human reference sequence tier.

Also report block-bootstrap uncertainty for the already declared GC-matched
subset, and shift each sequence window by -100/+100 bp using the existing
fitted sequence model without refitting or selecting the better shift. These
checks cannot make the test independent of its single pooled source or certify
new donors, states, disease effects or interventions. No candidate is scored
with, or ranked by, the benchmark classifier.

The released peak labels were generated by the source pipeline across the
genome. Version 1 is a retrospective classification of these fixed external
labels, not a raw-read pipeline with train-only peak/bias estimation. This is
a declared deviation from that broader acceptance goal. No count/profile or
bias-corrected model is claimed.
# Adversarial review follow-up, 10 September 2026

After inspecting v1 test results, add `python -m pmp22_atlas comparability`.
This recomputes CpG from reference sequence, verifies sequence hashes, exports
test composition and scores the original predictions in explicit TSS strata.
No labels, splits, models, hyperparameters or original metrics are changed.
These are post-review exploratory diagnostics, not a new independent test.
GC matching retains 28.3% of examples and changes promoter proximity; its AP
cannot be compared with all-test AP as a causal decomposition of GC effects.
Each subgroup reports prevalence. A distance-based stratum is not an enhancer
label. CpG-only ranking measures residual composition, not motif mechanism.
