# Matched inactive-region negative control

- **Priority:** 5
- **Direction:** No material PMP22 change expected.
- **Decisive experiment:** Apply the same reagent modality to a distance-, chromatin-, and sequence-matched region lacking PMP22 evidence in the same cells and batches.

The final interval must be selected using training data only and frozen before
test outcomes are inspected. This control estimates nonspecific modality and
local-chromatin effects; it cannot prove absence of all regulatory function.
