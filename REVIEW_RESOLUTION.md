# Adversarial review corrections and reanalysis

This correction follows the review of release `540633f`. The original binary
benchmark remains frozen; the reanalysis exposes its conditional population
and scope rather than relabeling a post-review result as independent validation.

| Review finding | Action completed | Remaining boundary |
|---|---|---|
| Intronic 50% effect used the wrong denominator description | AE011 now records reduction in EGR2 fold induction, with both construct-specific baselines; AE012/13 clarified; reported n=6 restored; dossiers and report corrected | Measurement independence and numerical uncertainties unresolved; no cross-assay potency ranking |
| GC matching changes test populations and leaves CpG differences | New comparability command verifies reference sequence, exports composition, GC/CpG-only rankings and frozen-model TSS-stratum scores; figure separates populations | Post-review exploratory results; no distal-enhancer, human-state or perturbation validation |
| Sham-only C overlaps do not identify an injury effect | Removed neighborhood peak counts from C prioritization; added chain-candidate audit, filtered counts and explicit evaluation status; whole-nerve composition caveat added | No exact C differential peak or human state effect established |
| Evidence rows reuse source peaks | Matrix now carries evidence_family_id, source_interval_ids and donor_ids; report explains the 25,903 bp peak shared across five regions | Family labels track dependence, not independent sample size; target assignment still missing |
| Unsupported statistical provenance | Removed ANOVA-only assertion for mouse RNA; retain author significance without inventing a panel-specific test | Pairing map and conduction-endpoint wording remain unresolved; no recalculated source P values |
| Closed controls do not match accessible recruitment context | Added two proposed accessible comparison intervals with BED/FASTA, source peaks, selection rules and strengthened occupancy/local-modulation requirements | All four DNA controls are untested; effects on PMP22/other genes require measurements |

Reanalysis confirms 830/1,060 original positives within 2 kb of annotated TSSs,
versus 161/300 in the GC-matched subset. Pure GC ranking has AP 0.506 in that
subset; CpG ranking has AP 0.679. Beyond 2 kb in the matched subset, frozen
sequence AP is 0.580 and AUROC 0.746, on 139 positives and 247 backgrounds
(prevalence 0.360). These are different populations, not a correction factor
to subtract from the original AP. The raw score 0.966 remains numerically valid
for its original task, with a narrower interpretation.

Accessible comparison sites are GRCh38 chr17:62694510–62694919 and
chr17:34199943–34200352, half-open. They were selected from stringent pooled
ATAC without PMP22-expression outcomes, outside the original locus neighborhood
and annotated promoters/transcripts, with length/GC matching. Their role is to
test recruitment and effector context; they are not proven functional negatives.

The human atlas observations and qualitative native rodent prior remain. New
native human noncoding perturbations, replicated human states and suitable
independent model-validation labels cannot be generated by rerunning these
public processed inputs. Those scientific acceptance gates remain open.
